Погода и часовой пояс

Погода обновляется из Open-Meteo примерно каждые 25 минут, ключ API не требуется для некоммерческого использования.

Видеозаставка

Для Raspberry Pi 4 начните с 1080p H.264 MP4. 4K в Chromium требует проверки на конкретной сборке.

Ночной режим

Видеотека

Онлайн-видео из выбранных источников, а просмотренные ролики остаются в ограниченном кеше на microSD.

Загрузка и обработка видео

Прогресс обновляется каждые 2 секунды. Для источников без известного размера или длительности процент не отображается, но объём, скорость и этап работы остаются видны.

Получаю сведения о загрузках…

Источники

Включайте и выключайте источники независимо. «Загруженные файлы» управляют только участием собственных видео в воспроизведении и не затрагивают онлайн-кеш. Apple Aerial (tvOS 26) и NASA не требуют ключей. Apple скачивается строго по одному видео: 1080p в приоритете, затем перекодирование в H.264 MP4.

Кеш подготовленных видео

Проверяю заполнение кеша…

Достигли лимита кеша или резерва свободного места (5 ГБ) — новые загрузки автоматически ставятся на паузу, уже готовые MP4 не удаляются. После увеличения лимита или освобождения места скачивание продолжится. Исходник удаляется после подготовки; история уже обработанных ID сохраняется.

Загрузить ролик

MP4 / WebM / M4V / MOV / MKV. После загрузки видео автоматически готовится в фоне: H.264, MP4, до 1080p/30 кадров/с. Совместимый H.264 перепаковывается без потери качества. Исходный файл сохраняется до успешного завершения; статус и повторная попытка доступны ниже.

Установка новой версии

Версия загружается во временную папку. Отдельная служба проверяет запуск; при ошибке возвращает предыдущую рабочую версию. Не обновляйте сторонними ZIP.
